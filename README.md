# Портфолио — Мухаммаджон Зоиров

Сайт-портфолио и резюме на трёх языках (RU / UZ / EN). React + TypeScript + Vite.

## Как поменять информацию
**Все тексты лежат в одном файле: `src/content.ts`.** Там контакты, опыт, проекты, навыки и образование, каждый текст на трёх языках.

- Добавить проект — скопировать блок в массиве `projects`.
- Главный проект — тот, у которого `featured: true`.
- Порядок навыков на сайте совпадает с порядком в файле, сильные навыки идут первыми (первые 3 в группе подсвечиваются).
- Фото лежат в `public/img/`: `portrait.webp`.

## Запуск
```bash
npm install
npm run dev
```

## Резюме PDF
Кнопка «Резюме PDF» открывает `public/resume-ru.pdf`, `resume-uz.pdf` или `resume-en.pdf`.
Если поменяли `content.ts`, PDF нужно обновить:
1. `npm run dev`, откройте `http://localhost:5173/?lang=ru`.
2. Нажмите **Ctrl + P**, выберите «Сохранить как PDF», отключите «Колонтитулы» и включите «Фон».
3. Сохраните как `public/resume-ru.pdf`. То же самое повторите для `?lang=uz` и `?lang=en`.

Для печати есть отдельная вёрстка, поэтому PDF выглядит как обычное резюме.
